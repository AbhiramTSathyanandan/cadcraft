# CADCraft drawing reference for the Craneye assistant

This is everything the assistant needs to operate the embedded editor: the tools it is given,
the control protocol behind them, the conventions of the lift-plan drawing it is editing,
recipes for common edits, and the full command catalogue (generated from the engine).

## 1. Tools (what the assistant can call)

Each call is one step. Results are JSON. A failing call returns `error` instead of throwing.

| Tool | Use it for | Notes |
|---|---|---|
| `execute {command, params?}` | Any engine command with JSON parameters. **Preferred** — deterministic, no prompts. | `command` is an id from the catalogue below (e.g. `properties.set`, `move`, `circle`). Reply: `{ok, result}`; `result` is the command's own value (counts, handles, data…). |
| `query_entities {type?, layer?, window?, crossing?, limit?, offset?}` | Find entities and their **handles** before modifying them. | = `execute entities`. `type` is `Line`, `Circle`, `Arc`, `Polyline`, `Text`, `MText`, `Hatch`, `Dimension`…; `window` is `[[x0,y0],[x1,y1]]`, `crossing:false` = entirely inside. Returns `{count, returned, offset, entities:[{handle, type, layer, color, geometry}]}`. |
| `inspect_drawing {entities?, limit?}` | Counts, extents, layers, current layer, selection, undo history. | Keep `entities:false` unless you need every object; use `query_entities` with a filter instead. |
| `command_line {text}` | Type one line at the command line like a user (`line 0,0 @10,0`, `zoom e`, `u`). Spaces act as Enter. | Use for interactive commands only when `execute` has no parameter form. |
| `script {text}` | Several command-line inputs, one per line; a blank line = Enter. | `TEXT` keeps asking for more lines until an empty one — end a TEXT script with a blank line. |
| `list_commands {filter?}` | Look a command up. | Rarely needed — the catalogue below is complete. |
| `cancel {}` | Escape: cancel the running command or clear the selection. | Call it if a `command_line` left a prompt open. |
| `zoom_extents {}` | Fit the drawing in the view. | |

## 2. Protocol facts

- **Handles** are hex strings the engine assigns (`"103"`, `"12F"`). They come from `query_entities` / `inspect_drawing`. Never invent one.
- `execute` replies `{ok:true, result:{…}}` or `{ok:false, error:"…"}`. Drawing commands return the new entity's handle(s) in `result` (e.g. `{handle:"1A3"}` / `{handles:[…]}`) — use that handle to set its layer or colour next.
- Coordinates are `[x, y]` arrays in drawing units (metres here). Angles are degrees, anticlockwise.
- Colours: `"ByLayer"`, `"ByBlock"`, a name (`red yellow green cyan blue magenta white`), an ACI index `1..255`, or `"r,g,b"` (purple = `"128,0,128"`, orange = `30`).
- Layers: new entities go on the **current** layer. `layer.current {name}` switches; `layer.new {name, color?, current?}` creates; `properties.set {handles, layer}` moves existing entities.
- Undo is one step at a time: `command_line {text:"u"}`. Everything the assistant does is undoable by the user.
- Text: `text {at:[x,y], text, height, rotation?}` (single line). For several lines make several TEXT entities 1.2×height apart, or `mtext`.

## 3. The lift-plan drawing (what is already there)

Generated by Craneye from the solved lift. Units metres; +x toward the load; +y up; ground at y=0; slew centre at x=0.

| Layer | Contents |
|---|---|
| `GROUND` | ground line, hatch strokes below it, slew centreline (dashed vertical at x=0), "CL slew" |
| `CRANE` | carrier/crawler, outriggers & pads, superstructure, counterweight, cab (closed polylines + circles for wheels) |
| `BOOM` | boom sections (closed polylines) or lattice chords, jib, head sheave + foot pin circles, "Main boom … m" label, angle arc |
| `RIGGING` | hoist falls (lines), hook block (rect), slings |
| `LOAD` | load box (closed polyline), hatch lines, CoG circle + cross, load description text |
| `OBSTACLE` | the obstacle rectangle (closed polyline, x = obstacle radius, 0.8 m wide) and its labels — only when the plan entered one; otherwise two warning notes |
| `DIMS` | red dimension lines with tick marks and labels: Radius, Boom tip, Hook, load height; boom-to-load clearance line |
| `TEXT` | headers and notes |
| `TITLE` | title block (border + rows of text) below the ground line |
| `PLAN` | plan view, offset to the right (centre at x ≈ elevation extent + 10 m + ext): tail-swing circles, outrigger/track footprint, house, boom, load footprint |

Rules of the house:
- Values that come from the lift engine (capacity, radius, boom length/angle, heights, utilisation) are **never** changed in the drawing. Offer to annotate instead.
- Modify existing objects in place by handle (`properties.set`, `move`, `scale`, `erase`). Do not draw a second copy of something that exists.
- Put notes on `TEXT` (or a new `NOTES` layer), height 0.3–0.5 m.
- After editing, call `inspect_drawing {entities:false}` once, then answer in ONE sentence.

## 4. Recipes

| Ask | Steps |
|---|---|
| Recolour the obstacle | `query_entities {layer:"OBSTACLE"}` → `properties.set {handles:[…], color:"magenta"}` (or `layer.set {name:"OBSTACLE", color:"magenta"}` for the whole layer) |
| Move the obstacle 2 m right | `query_entities {layer:"OBSTACLE"}` → `move {handles:[…], delta:[2,0]}` |
| Make the obstacle narrower | `query_entities {layer:"OBSTACLE", type:"Polyline"}` → `scale {handles:[h], base:[cx,0], factor:0.5}` (base = its centre x on the ground) or redraw via `properties.set` geometry fields |
| Add a note at the hook | `text {at:[radius+0.5, hookHeight], text:"4-leg sling", height:0.4}` → `properties.set {handles:[new], layer:"TEXT"}` |
| Exclusion circle around the load in plan | find the plan load footprint (`query_entities {layer:"LOAD"}`; the one with x > 20 is the plan copy) → `circle {center:[cx,cy], radius:3}` → `properties.set {handles:[new], layer:"OBSTACLE", color:"red"}` → `text` label |
| Delete something | `query_entities …` → `erase {handles:[…]}` |
| Change text wording | `query_entities {type:"Text"}` → `properties.set {handles:[h], text:"new wording"}` |
| Draw on a specific layer | `layer.current {name:"NOTES"}` (create with `layer.new` first) → draw → `layer.current {name:"0"}` |
| Fit the view | `zoom_extents` |
